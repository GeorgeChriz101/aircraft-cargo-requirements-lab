# Requirements Traceability Matrix

The Requirements Traceability Matrix links customer needs to system requirements, interface requirements, verification methods, and planned test cases.

The purpose of this matrix is to confirm that each customer need is addressed by one or more technical requirements and that those requirements can be verified.
