# Verification Methods

The project uses simplified systems-engineering verification methods.

## Test

The system behavior is exercised using defined inputs and the resulting outputs are compared against expected behavior.

Example:

Provide an OPEN command and verify that the system initiates door opening when safety conditions are satisfied.

---

## Inspection

The design, documentation, interface definition, or implementation is reviewed directly.

Example:

Inspect the interface definition to confirm that aircraft power availability is provided to the cargo door control system.

---

## Test and Inspection

Some requirements require both review of the design/interface and execution of system behavior.

Example:

The aircraft power requirement can be inspected for the defined interface and tested to confirm correct operation when power is available.
