# Customer Needs

The following customer needs define the high-level expectations for the Aircraft Cargo Door Control System.

## CN-001 — Safe Door Operation

The cargo door should open and close safely when commanded by an authorized operator.

## CN-002 — Door Position Awareness

The operator should be able to determine whether the cargo door is open, closed, or in transition.

## CN-003 — Locking Confirmation

The system should provide confirmation that the cargo door is securely locked before aircraft operation.

## CN-004 — Unsafe Command Prevention

The system should prevent door movement when unsafe operating conditions are detected.

## CN-005 — Fault Notification

The system should notify the operator when a sensor, actuator, or locking fault is detected.

## CN-006 — Reliable Power Interface

The cargo door control system should operate using the aircraft electrical power interface provided to the system.

## CN-007 — Maintenance Support

Maintenance personnel should be able to identify system faults during troubleshooting.

## CN-008 — Controlled Door Movement

The door should move in a controlled manner during opening and closing operations.
